default selected every lane for PR-template, Dependabot and observability edits.

configs now name their execution workflows, shared actions, locks and policy
inputs explicitly. Regression tests exercise real Git changes and fail if those
boundaries broaden or lose required coverage.

## Method and limits

Runner-seconds sum executed-job start-to-completion intervals, including setup
and cleanup. Elapsed spans workflow creation through the last executed job;
combined elapsed is the parallel workflows' span, not their sum. Skipped jobs
count zero. PR-title workflows and independent completed-run observers are
outside these validation totals. No billing or dollar saving is inferred.

The observations include cache, network, runner and order variance. One pair
does not establish a stable average. The exporters reject unsuccessful or
incomplete attempts; a cancelled superseded Due run is not counted as a saved
test execution. Both successful runs above are retained in the raw data.

```bash
uv run python scripts/measure_ci_runs.py gigaverse-app/pytest-selective \
  39849575401 39849815319 --output selective-docs.json
uv run python scripts/measure_ci_runs.py gigaverse-app/due \
  39849835910 --output due-docs-ci.json
uv run python scripts/measure_ci_runs.py gigaverse-app/due \
  39849835994 --output due-docs-widget.json
```
